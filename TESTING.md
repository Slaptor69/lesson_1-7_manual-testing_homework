## BUG-01. Заявка с пустым именем

- Требование: R1. Можно отправить заявку без имени.
- Условия: обычный режим, три исходные заявки.
- Шаги: ввести два пробела в имя, выбрать «HTML и CSS», оставить комментарий пустым и отправить.
- Ожидалось: ошибка имени, новая заявка не появляется.
- Получилось: показан успех, появилась четвёртая карточка без имени.
- Исправление: `src/app.js` — пробелы по краям убираются до проверки длины. Commit `a92e84c`.
- Повторная проверка: имя из пробелов отклонено, осталось три заявки.
- Соседняя проверка: имя из одной буквы отклонено, из двух — принято без пробелов по краям. Для повтора: ` А ` и `  Ли  `. Без направления заявка не отправляется. Имя из 60 букв и комментарий из 200 букв принимаются.

## BUG-02. Неправильный счётчик

- Требование: R2. Число рядом со списком не совпадает с карточками.
- Условия: обычный режим, исходные заявки, до исправления — commit `a92e84c`.
- Шаги: выбрать фильтр «HTML и CSS», затем «HTTP и API».
- Ожидалось: сначала одна карточка и счётчик 1, затем пустой список и 0.
- Получилось: карточки отфильтрованы, но счётчик в обоих случаях показывает 3.
- Исправление: `src/app.js` — считаются только карточки выбранного направления. Commit `0ef61a6`.
- Повторная проверка: для HTML показано 1, для API — 0 и сообщение о пустом списке.
- Соседняя проверка: JavaScript — 2, все направления — 3. После добавления API-заявки счётчик API стал 1 и сохранился после «Обновить». Для повтора: «Килиан Мбаппе», «HTTP и API».

## BUG-03. Нажатие на имя не выбирает карточку

- Требование: R3. Не открываются подробности заявки.
- Условия: исходные заявки, фильтр «Все направления», до исправления — commit `a92e84c`.
- Шаги: нажать имя «Анна Лебедева» в первой карточке, затем выбрать эту карточку через Enter.
- Ожидалось: оба способа открывают данные Анны.
- Получилось: нажатие имени ничего не выбирает, Enter работает.
- Исправление: `src/app.js` — убрана проверка, которая пропускала нажатия на текст внутри карточки. Commit `0ef61a6`.
- Повторная проверка: имя и Enter открывают одну и ту же заявку.
- Соседняя проверка: номер, направление, комментарий и стрелка тоже выбирают карточку. Tab переводит фокус между карточками, Enter выбирает нужную. При обновлении выбор остаётся, при скрытии карточки фильтром снимается.

## BUG-04. Интерфейс сбрасывается не полностью

- Требование: R4. После сброса остаются фильтр и выбранная заявка.
- Условия: исходные заявки, до исправления — commit `a92e84c`.
- Шаги: выбрать фильтр JavaScript и карточку №2. Заполнить форму: «Криштиану Роналду», «HTTP и API», «Проверка сброса». Нажать «Сбросить интерфейс».
- Ожидалось: пустая форма, все направления, ни одна карточка не выбрана. Заявки остаются.
- Получилось: очищена только форма, фильтр и подробности карточки остались.
- Исправление: `src/app.js` — сбрасываются фильтр и выбор карточки. Commit `0ef61a6`.
- Повторная проверка: форма очищена, видны все три заявки, выбора нет. Повторный сброс ничего не ломает.
- Соседняя проверка: после добавления API-заявки сброс и перезагрузка сохранили все четыре заявки. Для повтора: «Килиан Мбаппе», «HTTP и API».

## BUG-05. Кнопка не помещается на телефоне

- Требование: R5. Для просмотра кнопки нужна прокрутка вправо.
- Условия: окно 360 × 800 px, обычный режим, до исправления — commit `0ef61a6`.
- Шаги: открыть форму и проверить, помещается ли кнопка отправки.
- Ожидалось: форма и кнопка помещаются по ширине.
- Получилось: кнопка шириной 380 px выходит за край страницы.
- Исправление: `src/styles.css` — убрана минимальная ширина 380 px у кнопки. Commit `594f9af`.
- Повторная проверка: на 360 px прокрутки вправо нет, заявка отправлена успешно. Для повтора: «Лионель Месси», «HTTP и API», «Проверка формы на 360 px».
- Соседняя проверка: на ширине 375 и 1280 px форма и кнопка тоже помещаются.

## BUG-06. Две одинаковые заявки

- Требование: R6. Повторное нажатие создаёт дубли.
- Условия: исходные заявки, режим «Задержка 2 секунды».
- Шаги: заполнить «Криштиану Роналду», «JavaScript и DOM», «Проверка повтора». Дважды быстро нажать отправку и дождаться ответа.
- Ожидалось: одна новая заявка, всего четыре.
- Получилось: появились две одинаковые заявки, всего пять.
- Исправление: `src/app.js` — повторная отправка не запускается, пока идёт первая; кнопка на это время отключена. Commit `a92e84c`.
- Повторная проверка: двойное нажатие и дополнительный Enter создали только одну заявку. После ответа кнопка снова доступна.
- Соседняя проверка: следующая заявка отправилась отдельно. Для повтора: «Килиан Мбаппе», «HTML и CSS». Сброс стенда во время задержки не мешает новой отправке.

## BUG-07. Теги в комментарии стали разметкой

- Требование: R7. Комментарий должен показываться обычным текстом.
- Условия: обычный режим, исходные заявки, до исправления — commit `0ef61a6`.
- Шаги: отправить заявку «Криштиану Роналду», «HTML и CSS», комментарий `<b>Тест</b> & <i>текст</i>`. Открыть карточку, затем перезагрузить страницу и открыть её снова.
- Ожидалось: вся строка вместе с тегами видна в карточке и подробностях.
- Получилось: виден только текст «Тест & текст» с форматированием. После перезагрузки то же самое.
- Исправление: `src/app.js` — комментарий выводится через `textContent` вместо `innerHTML`. Commit `594f9af`.
- Повторная проверка: теги видны как текст в обоих местах и после перезагрузки. Старый сохранённый комментарий тоже показывается правильно.
- Соседняя проверка: пустой комментарий показывает «Без комментария». Строка `&lt;b&gt; & "кавычки" < >` сохраняется и выводится без изменений.

## BUG-08. При ошибке показывается успех

- Требование: R8. Форма теряет данные, хотя заявка не сохранена.
- Условия: исходные заявки, режим «Ошибка 503».
- Шаги: заполнить «Лионель Месси», «HTTP и API», «Проверка ошибки» и отправить.
- Ожидалось: сообщение об ошибке, данные остаются, можно повторить отправку.
- Получилось: показан успех, форма очищена, новой заявки нет.
- Исправление: `src/app.js` — проверяется ответ сервиса; при ошибке форма не очищается. Commit `a92e84c`.
- Повторная проверка: показана ошибка, значения остались, заявок по-прежнему три. Повтор при ошибке дал тот же результат.
- Соседняя проверка: в обычном режиме эти же данные сохранились, появилась одна новая карточка, форма очистилась. После перезагрузки заявка осталась.
